# 직접 확인 목록 (점검 단계 8)

설치된 개인용 빌드(점검 수정 포함, 버전 표시는 1.4.2)로 확인한다. 결과는 각 줄 끝에 ○(정상) / ×(이상, 증상)로 적거나 말로 알려 주면 `AUDIT_RESULTS.md`에 옮긴다. **가**는 이번 점검에서 동작을 바꾼 곳이라 꼭 확인해야 하고, **나**는 바꾸지 않았지만 자동으로 볼 수 없던 곳이다.

## 가. 이번에 바꾼 곳 (꼭 확인)

| # | 확인할 것 | 방법 | 정상이면 | 이상하면 |
|---|---|---|---|---|
| 1 | Mission Control에서 노치 숨김 | ⌃↑, 트랙패드 세 손가락 위로, 핫코너로 각각 5회 이상 열고 닫기. 빠르게 열었다 닫기도 | 열 때마다 노치가 바로(0.3초 안) 줄어들며 사라지고, 닫으면 돌아온다 | 늦게 숨거나 안 숨음, 닫았는데 안 돌아옴 → 알려 주면 확인 시간을 원래 값으로 되돌린다 |
| 2 | 전화 수신·통화 | iPhone으로 걸려 오는 전화 1통: 수신 카드, 받기, 통화 중 표시, 음소거, 끊기. 가능하면 거절도 1회 | 수신 카드가 바로 뜨고 버튼이 동작, 끊으면 노치에서 사라진다 | 카드가 늦게 뜨거나 안 뜸, 끊었는데 남음 |
| 3 | Wi-Fi·VPN·핫스팟 알림 | Wi-Fi 끄기/켜기, 다른 네트워크로 바꾸기, VPN 연결/해제(쓰는 경우), 개인용 핫스팟 연결(쓰는 경우) | 예전처럼 알림이 뜬다 | 알림이 안 뜨거나 늦음 |
| 4 | 화면 녹화 표시 | ⌘⇧5로 녹화 시작·정지. 설정에서 화면 녹화를 껐다 켠 뒤 다시 한 번 | 시작하면 빨간 점, 정지하면 "녹화 완료". 껐다 켠 뒤에도 동작 | 켠 뒤 표시가 안 나옴 |
| 5 | AI 사용량: 숨긴 뒤 쉬기 | 두 손가락 위로 상시 표시를 숨기고 새로고침 주기(설정값)보다 오래 둔 뒤, 두 손가락 아래로 다시 보이기 | 다시 보이면 곧 최신 값으로 바뀐다 | 값이 오래된 채로 남음 |
| 6 | 홈 페이지 순서 | 노치를 열어 페이지를 넘겨 보기. 자원 사용량 홈 기능을 켜면 | 자원 사용량이 AI 사용량 바로 다음에 나온다 | 다른 자리에 나옴 |
| 7 | 스크린샷 감지(파일 저장 방식을 쓰는 경우) | ⌘⇧3 한 번 | 미리보기 카드가 뜬다 | 안 뜸 |
| 8 | 숫자 설정 | 설정 → 일반에서 길게 누르기 시간, 드래그 감지 높이, 배터리 부족 기준을 바꿔 보기 | 값이 그대로 저장되고 동작에 반영 | 값이 튀거나 저장 안 됨 |
